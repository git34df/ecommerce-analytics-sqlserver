# Ecommerce Analytics — SQL Server & Power BI

## Objetivo
Análisis de comportamiento de ventas, clientes y productos
de una tienda ecommerce usando SQL Server como motor analítico
y Power BI para visualización.

## Stack
![SQL Server](badge) · ![Python](badge) · ![Power BI](badge)

## Contenido
| Carpeta | Descripción |
|---------|-------------|
| `data/` | Datasets CSV originales |
| `sql/` | Script de conexión y consultas analíticas |
| `dashboard/` | Capturas y archivo .pbix |

## Consultas destacadas
- Top 10 productos por revenue
- Análisis de clientes recurrentes
- Tendencia mensual de ventas
